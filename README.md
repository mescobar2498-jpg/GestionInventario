# Sistema de Gestión de Inventario

Aplicación de consola en C#/.NET para gestionar inventario, 
stock y reportes básicos de productos.

## 🚀 Tecnologías
- C# / .NET 8
- (Aquí agregarías: Entity Framework, SQL Server, xUnit, etc. según crezca)

## 📋 Funcionalidades
- Registro y consulta de productos
- Control de stock (entradas/salidas)
- Generación de reportes de inventario bajo

## 🔧 Cómo ejecutar el proyecto
\`\`\`bash
git clone https://github.com/mescobar2498-jpg/GestionInventario.git
cd GestionInventario
dotnet run
\`\`\`
